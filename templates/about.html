About LungSense AI

A machine learning system that detects respiratory diseases from lung sound recordings — built as a mini project using the ICBHI 2017 dataset and trained with Random Forest classification.

🎯

Project Goal

Build an AI model that can classify lung sounds into Normal, Crackle, Wheeze, or Both — and serve the results through a web application accessible to anyone.

🌍

Real-World Impact

Respiratory diseases affect 1 billion people worldwide. This tool aims to enable early screening in resource-limited settings where stethoscope-trained doctors are scarce.

🧠

How It Works

Audio → MFCC feature extraction (122 features per segment) → Random Forest Classifier → Prediction with confidence score.

📊

Model Performance

Trained on 6,898 respiratory cycles from 126 patients. Handles class imbalance with class_weight='balanced'. Target accuracy: 80%+.
